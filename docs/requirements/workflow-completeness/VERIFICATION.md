## 关键行为覆盖

- 候选复审绑定确切 commit、tree 和 PRD；设计变化阻止合入，修复与重新验证使旧复审失效。
- 集成中改写固化设计时失败；候选必须包含源交付与目标基线。
- 同模块独立提案分别验收，未合入设计不成为其他主线需求的依据；文档合并后发布与 Git 内容对应的独立模块版本，原 PRD 不变。
- 仓库模块文档随交付封存，正文与提案不同则拒绝封存。
- 讨论提案按版本提取，不自动确认，拒绝串需求或项目；浏览器中采用后仍待新 PRD 确认。
- 自动封存与真实检查通过、失败日志进入修复、次数耗尽、设计/配置变化暂停、启动失败、停止、重启中断。
- 停止与读取改动同时发生时，取消的自动轮次不会复活或继续封存。
- 排队需求占用名额时，自动轮次等待后继续验证，不误判为需要人工处理。
