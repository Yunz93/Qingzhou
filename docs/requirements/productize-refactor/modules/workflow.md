# 工作流重构完成后的设计提案

来源：productize-refactor PRD v1。状态：用户已授权实施，已完成三批源码改造与自测，待用户验收；不覆盖当前模块基线。

项目状态读取归专用 hook；项目导航、需求列表、交付/验收和候选复审分别维护自身交互，派生状态继续复用 requirement-state。PRD 草稿归独立编辑会话，集中结构校验、缓存恢复和保存响应，保留原键与准确 PRD 版本。

检查命令执行归薄平台适配器；WorkflowService 保持事实与调度所有权，包括配置/commit/tree 绑定、执行名额、资源锁、事件和检查有效性。适配器只拥有进程及输出，不生成验收或合入事实。

采用 productize-app 的对象身份/请求代次、编辑会话、失败后重试、低干扰界面和受控异步用例。沿用 Electron/React/Node 的等效能力，不复制其他项目的存储与发行配置。实现位置及通过范围分别见上级 IMPLEMENTATION.md、VERIFICATION.md；平台确认、人工验收和代码合入不由本文件生成。
