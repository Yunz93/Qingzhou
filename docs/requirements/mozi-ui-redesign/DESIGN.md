# 轻舟界面规范提案 v1

状态：随 PRD v1 获得实施授权，已实施并自测，待用户最终确认。引用 markdown-press 当前实现，不复用历史纯黑、衬线、亮绿或卡片方案。

## 1. 视觉方向

安静、直接、连续的本地工作空间。暖白或金属深灰组成同色画布，以陶土强调当前操作，文字与真实内容建立层级。

内容顺序：定位当前对象 → 阅读或输入 → 看见当前状态 → 执行下一步。界面不使用营销首屏、大字数据卡或装饰背景。

交互反馈：高频输入和键盘导航即时响应；普通按钮按下有轻微表面反馈，低频弹层只做短淡入；减少动态效果时关闭非必要动画。

## 2. 色彩角色

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| canvas | `#faf8f3` | `#24272b` | 标题、侧栏、主工作区、底栏 |
| surface | `#fffdf8` | `#2b2f35` | 菜单、弹层、表单输入 |
| text | `#2c2b28` | `#e4e1d9` | 正文与主要标签 |
| muted | `#746f67` | `#aaa79e` | 路径、辅助说明、次级状态 |
| border | `#ded9d0` | `#3a4047` | 必要输入边界与菜单边缘 |
| divider | `rgba(44,43,40,.1)` | `rgba(255,255,255,.08)` | 主面板淡竖线 |
| hover | `#eae5dc` | `#30353b` | 悬停反馈 |
| selected | `#f1e3d9` | `#363d45` | 选中行和当前控件 |
| accent-action | `#a65f43` | `#d49b7e` | 主动作背景 |
| accent | `#8f4e37` | `#d49b7e` | 文字强调、选中标签与焦点 |
| on-accent | `#fffaf4` | `#231e19` | 强调按钮文字 |

浅色强调文字使用参考产品已有的深陶土 `#8f4e37`，避免 `#a65f43` 在米色选中底上只有 3.86:1 的对比度；主按钮仍使用原陶土色。成功、危险、警告及 diff 增删继续使用轻舟语义角色；浅色文字分别采用 `#39734d`、`#b33936`、`#8a5a18`，信息文字为 `#326a91`，深色沿用原有语义色；陶土色不替代失败红或成功绿。浅竖线仅用于分区，不单独承担控件辨识或焦点指示。输入边界若达不到 3:1，采用更强的专用边界色。

## 3. 字体与密度

- 系统字体：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。沿用已有代码等宽字体，仅用于代码、命令和 diff。
- 工具栏/表单/导航 14px；辅助标签 12px；聊天和文档正文 15px、行高 1.75；小节标题 16px；页面标题 20px。标题不使用夸张字距。
- 字重控制在 400、500、600 三档，状态计数采用等宽数字。正文默认最长约 72ch，代码不强制折行。
- 间距使用 4/8/12/16/24/32px。密度调整通过容器和间距完成，不靠缩小全部文字。

## 4. 控件契约

- 圆角：小控件 6px、输入区和普通表面 8px、独立弹窗 12px。只在确有含义的状态标识上使用胶囊。
- 普通工具图标 14px，面板图标 16px；命中区最少 40×40px，触摸使用 44px，不让相邻点击区重叠。
- 主按钮陶土底，次按钮轻表面，低频操作为文字或图标按钮。hover、pressed、disabled、busy、focus-visible 各有明确状态。
- 危险操作保留红色语义和文字；确认、验收、合入按钮保留文字，不能缩成不明含义的纯图标。
- 菜单保留名称、tooltip、方向键、Home/End、Escape 与焦点返回；不照搬墨知只用图标的导出菜单到轻舟高后果流程。
- 输入区有可读标签、错误定位和未保存反馈；错误后保留输入，不通过 toast 单独表达关键结果。

## 5. 布局

- 复用现有对话侧栏与内容区；项目沿用原主导航，不新增活动栏或第二套项目树。
- 主工具栏一个层级，移除重复标题；公共工具图标化。项目直接进入导航与需求列表，运行信息按需打开，仅待处理或运行状态直接呈现。
- 需求双栏保留准确对象身份、默认比例和拖拽；审阅五页签保留文字。工具行紧凑、正文连续阅读、底部主要动作可达。
- 卡片只用于独立表单或实际可选择的对象，不为每个标题/说明/统计套框。首页只留新建对话；项目空态沿用工具行的新建入口；一个需求只显示一个当前关键状态；无操作的底部栏收起。

## 6. 深度与分隔

主区域同色，依靠间距、对齐和淡竖线组织。标题栏底线隐藏；菜单与聚焦弹窗使用一层轻阴影及明确实色背景。主界面不做毛玻璃，不模糊内容以制造层级。

分隔器静止时轻淡，悬停、拖动、focus-visible 时清晰；键盘仍可调整。隐藏装饰线不改变尺寸或命中位置。

## 7. 复用的经验与禁止项

1. 以当前源码和最新验收修订为准，不把旧截图中的风格再次带回。
2. 小图标保留点击面积、可访问名称和键盘导航；危险与流程主动作仍用文字。
3. 浅色/深色从共享 token 覆盖菜单、设置、输入、启动页和辅助工具，避免只改主画布。
4. 保持编辑器与表单身份，避免布局变化触发旧内容回写或丢草稿。
5. 正文、表格和代码依同一内容边缘对齐，局部宽内容单独滚动。
6. 实际 Electron 字体、拖拽标题栏和最小窗口必须验证；墨知的 WKWebView 特定绕过方案不搬入轻舟。
7. 去掉重复提示和无意义的空计数；阻断原因、未保存修改和真实失败必须保留。
8. 不新增复杂主题引擎，不引入装饰图片、背景渐变、厚侧边条或成组大统计卡片。

## 8. 响应与输入

正常桌面使用现有双栏；不足以同时容纳两区时沿用原单区切换与专注模式。窄屏先保住正文、输入和主要动作，再折叠辅助工具。支持 390px 宽、200% 缩放、长中文标题和真实多文件 diff。

具体 Electron 最小宽高以当前 `BrowserWindow` 配置为依据；实施前读回核对。窗口布局不继承参考应用的 960×640 阈值。

- 新表单：surface 输入，14px 标签，8px 圆角，字段间距 16px；错误红色文字定位到字段，保留值和重试入口。
