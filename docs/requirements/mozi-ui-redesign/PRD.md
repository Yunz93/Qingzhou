完整规范见 [DESIGN.md](DESIGN.md)。采用同色画布、系统无衬线字体、小图标、轻竖线与陶土强调：浅色 `#faf8f3`，深色 `#24272b`；浅色强调 `#a65f43`，深色强调 `#d49b7e`。

主界面沿用侧栏、内容和辅助面板结构，不增加导航层。顶部普通工具改为 14px 图标和统一点击区域，保留 tooltip 与可访问名称；创建、发送、确认、验收、合入等需要理解后果的操作保留文字。状态同时用文字表达。

标题栏与内容区同色，去掉多余的水平框线、重复卡片和常驻阴影；侧栏与正文、对话与审阅之间保留淡竖线，拖拽分隔器在悬停、拖动及键盘聚焦时清晰可见。

## 5. 行为契约

### 5.1 进入与创建

- 首页只保留新建对话主入口；进入工作由已有模式导航承担，移除介绍、示例按钮组和重复项目入口。示例提示集中到已创建对话的输入场景。
- 新建对话/项目优先显示已选目录摘要和必要字段；浏览目录、手输路径按需展开。已选目录必须可见且可修改，不自行扩大允许根目录。
- 创建需求保留标题、目标、验收标准三项及现有草稿语义，不增加额外向导。
- 对话转需求保留来源片段与范围确认；无项目时给可操作的创建项目入口，返回后保留原表单、来源和焦点。复用现有新项目弹窗及服务，不自动创建或自动实施。

### 5.2 对话与输入

- 统一系统字体、正文行宽和消息间距，减少大块背景和常驻复制/克隆操作的视觉权重；键盘与触摸仍能访问。
- 输入区优先消息、附件和发送；“追加/排队”仅在回复中或有待发消息时呈现，不重置用户已选策略。
- 模式弹层删除重复滑杆，用带明确标签的单选项；交互模式与审批策略仍分别可选，选项、默认值和权限语义不变。保留必要的高风险选项说明。
- 回复中、等待审批、等待回答、断线、失败均有准确反馈；草稿、附件、滚动位置和恢复入口继续保留。Esc 关闭当前弹层，不误停止回复；中文输入法确认候选不触发发送。

### 5.3 项目总览

- 项目标题由现有标题栏承担；内容直接从项目页签和任务工具行开始。设置以图标进入，运行详情、主线检查与调度进入更多操作；仅运行中、暂停、失败和需处理时显示相应状态。移除总览、统计和分支状态的常驻占位。
- 原有需求、待处理、集成队列、模块文档、项目历史继续可达；不另建一套导航或统计。
- 无需求时保留一个新建主入口，隐藏无效的列表批量操作；筛选集中为一个有名称的状态选择器，保留全部六类筛选、数量和现有查询/恢复行为。列表/看板切换仍保留。
- 暂停调度与主线验证从低频项目操作进入，正在运行或暂停时直接显示状态和恢复/停止入口。

### 5.4 需求与审阅

- 保留连续对话与审阅双栏、可调宽度和五页签：设计、模块设计、交付、验收、历史。沿用当前 61% 审阅默认宽度、专注模式和旧深链兼容。
- 同色表面、轻分隔与紧凑工具行替代嵌套卡片；标题只承担对象定位，状态只显示一次。
- 有操作时通过固定底部操作区呈现当前阶段的主要动作，无操作时收起该区域；低频工具放在已有详情或更多中。不能隐藏阻断原因、失败日志入口、未保存修改或过期依据。
- 单个需求隐藏无意义的翻页控件；对话不重复显示区域标题，PRD 工具行只显示当前可执行的阅读或编辑切换，范围入口沿用需求更多操作。
- 设计默认阅读，编辑/预览/保存分明；页签切换、异步更新和关闭重开不丢草稿。保存、范围确认、PRD 确认、开始实施仍是不同动作。
- 模块设计继续对照准确基线；交付/验收共用所选交付；历史只读、保留准确版本。无关联模块和无交付采用简短空态与一个相关返回入口。
- 确认范围、确认 PRD、文件归属、人工验收、候选复审与最终合入继续明确操作，不能合并或自动批准。

### 5.5 设置与辅助工具

- 设置导航、表单、菜单和弹窗复用同一套文字、间距、圆角和表面；当前分组一次只显示相关设置。
- 应用设置与项目编排设置的职责保留；返回后恢复原任务、搜索和草稿。设置表单不因主题切换或返回丢失输入。
- 文件、Git、终端、浏览器、资源保持原入口及能力；按需打开，统一工具栏与空态。已有资源草稿、路径来源和保存失败保留。
- 普通工具可纯图标，带后果的审批、提问、删除、恢复和合入按钮保留明确文字及现有保护。

## 6. 技术决策与最大风险

采用现有 CSS token 和语义 class 调整，Tailwind 用于原有布局工具；避免叠加一份大范围高优先级覆盖样式。按组件删除被替代规则，保留既有布局钩子和可访问属性。

最大风险是结构调整导致草稿重挂载丢失、隐藏主操作、弹层焦点回退错误，以及自定义颜色只覆盖主页面。先以需求主界面和设置验证共享角色，再扩展；保持组件身份和现有持久化键，所有交互改动补行为回归。桌面与浏览器分别验证，浏览器通过不能代替 Electron 验收。

## 8. 验收标准

1. 所有主要页面、弹窗与输入控件在两种主题下使用相同角色；正常文字对比度达到 WCAG AA 4.5:1，控件和焦点边界达到 3:1，状态不只依赖颜色。
2. 对话和工作首页各只有一个同级新建主动作；空列表不显示无效批量选择；六类状态均可筛选且返回/刷新保持现有恢复行为。
3. 模式选择无重复滑杆；权限选项及默认值不变，用户能看到当前选择和高风险选项后果。
4. 发送、等待、停止、失败重试与附件保留可完成；键盘、IME、Esc 和焦点返回不退化。
5. 五页签、模块准确基线、差异审阅、历史版本和全部关键确认可达；设计草稿切换、关闭重开和异步刷新不丢失或被旧回调覆盖。
6. 转需求缺项目时可创建并回到原表单；已有目标、来源、验收内容保持，不自动确认范围或开始执行。
7. 1440×900、1280×800、Electron 当前最小尺寸及 390×844 窄屏均可完成主要任务，无整页横向溢出；代码/差异可局部滚动。200% 缩放和长中文标题仍可操作。
8. 隔离项目完整完成确认、实施、封存、真实检查、人工样例验收、候选复审与样例合入；报告明确 fake Pi 的证据边界。正式用户项目与平台事实不被改写。
9. 相关检查真实通过，完成代表性 Electron 运行检查，并由用户确认效果；未覆盖项逐项列出，不以文档或截图自动宣称验收。
