# 模式与审批切换回写修复

版本：v1。依据用户本轮“发布新版本”的授权，修复发版检查复现的既有交互缺陷，不改变审批语义或补造平台确认记录。

## 问题与目标

快速从代理切到规划再回到代理时，当前 props 仍可能等于切换前的值。旧实现据此过早清除本地待确认选择，较早的规划回写随后会覆盖最新选择，短暂禁用审批选项，导致点击“自动通过”无效。

## 范围与验收

- 等待最新一次模式 / 审批保存请求确认，并且服务器值与这次选择一致后，才清除本地待确认状态。较早请求的确认不能清除新选择。
- 保留连续选择和即时反馈，不用禁用整个选择器代替正确处理回写；保存成功后刷新仍显示最后选择。
- 最新保存失败时恢复已保存选择，使用现有错误反馈并允许重试。
- 自由对话与需求内嵌对话采用同一契约；只读讨论、审批规则及服务端校验保持不变。
- 新增延迟较早请求确认的确定性浏览器回归及保存失败 / 重试回归，保留原有选择器与核心发送流程断言。
