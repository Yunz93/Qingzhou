# 模型接入与工作台提案

来源为[首用与商用就绪 v1](../PRD.md)，参考[执行与权限](../../../modules/agent-runtime.md)、[对话](../../../modules/conversation.md)以及[桌面界面提案](../../tauri-desktop/modules/ui-experience.md)。

- 向导和设置共用服务商名称、凭据来源和 Gemini 验证动作。官方连接可从本地服务向 Google 获取模型目录。自定义配置显示接收凭据的主机，并在服务端核对用户确认的目标后保存。实际生成沿用 Pi 的 Google provider。
- 工作区将对象名称、内容和当前可执行动作分层；窄窗口把低频工具收进现有操作入口。打开、关闭导航或回到原需求时保留可见焦点。
- 小于 640 像素的需求工作区允许标题显示两行。状态和对话入口保持可见，有多项需求时把翻页控件放到次行。
- 桌面连接建立与认证配置读取分别进行。已保存的文件、项目和草稿仍通过现有本机持久化入口恢复。
