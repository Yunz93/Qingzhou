# 墨问首用与商用就绪 · PRD v1

用户目标是让墨问易用、层级清楚、科技现代简洁，并支持接入 Gemini。本轮从桌面迁移候选 `a9344f2` 继续。沿用[桌面设计](../tauri-desktop/DESIGN.md)的黑白「问」字、明暗主题和工作模式。此文档记录实现依据，人工验收由用户决定。

| 使用路径 | 验证条件 |
| --- | --- |
| 首次运行 | 有内置 Pi 时直接配置服务商和工作文件夹。已有凭据准确标出来源，连接和保存分开反馈。允许暂时跳过凭据浏览历史；首次创建的对话使用向导实际选定的目录。加载失败可重试。 |
| Gemini | 官方配置使用 Google AI Studio 密钥，可通过读取模型目录检查连通性。若 Pi 配有自定义 Google 服务，向导和设置展示实际接收主机，保存凭据前需确认当前目标。保存后可通过 Pi 选择 Google 模型、发起对话；删除本地凭据保留其他配置和环境变量。 |
| 工作区 | 窄窗口优先显示正在阅读的会话或需求名称；返回需求、创建对话和主要操作可用键盘或指针完成。辅助操作按上下文呈现。 |
| 启动与恢复 | 凭据检查较慢时仍可连接业务会话；重连保留草稿。只在实际失败的位置说明如何恢复。 |
| 交付 | 在隔离资料中验证首次配置、正常与异常、对话、项目流程、明暗主题和常用窗口尺寸。验证生产构建、实际桌面运行，以及内置 Pi 的 Gemini 数据链路。在线服务商账号、正式分发与人工判断分别记录结果。 |

模块提案见[模型接入与工作台](modules/model-and-workbench.md)。延续 Tauri、React 与现有 Pi 协议和权限。项目与对话历史保存在本机。用户主动测试官方连接时会向 Google 读取模型目录，发送消息时会向该模型配置的服务发送生成所需的内容。
