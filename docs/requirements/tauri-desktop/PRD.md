# 墨问桌面迁移与界面重设计 · PRD v2

本版本待确认。按最新要求，桌面迁移与全新界面一并交付，视觉以 Mozi（墨知）为参考。实施基线拟用本地 `origin/main` 指向的 `f76ee5488c1f98ede475ce3a785743afafcb66a7`。当前主工作区为 `f448319`，有独立的桌面包体精简未提交改动。实施时使用隔离工作区，逐项比对该轮的资源精简与架构校验规则。详见[桌面提案](modules/desktop.md)、[界面提案](modules/ui-experience.md)与[页面设计](DESIGN.md)。

## 目标与范围

用 Tauri 2 和系统 WebView 重新实现轻舟桌面应用，并以墨问（Mowen）为产品名，让安装包更小，能单独调试界面、桌面宿主和 Pi 服务。正式桌面版支持 macOS arm64、macOS x64 和 Windows x64。用户从安装或升级进入墨问，可继续已有项目与需求，也可新建对话、运行 Pi、查看终端和交付、退出后接着工作。

- Rust 桌面宿主负责窗口、菜单、系统对话框、打开文件、通知、更新及本地服务生命周期。Node/Fastify 业务服务与 Pi RPC 作为独立进程运行，保留编排、审批、Git、PTY 和存储规则。运行 Node、Pi 及配套工具随包提供，用户无需安装 Node 或 Pi。
- 用 React、TypeScript 和 Vite 从头编写页面、布局、导航和视觉组件。全新界面覆盖自由对话、项目列表、需求的设计与审阅、待处理、终端与文件、设置、首次启动及失败状态。协议、前端状态逻辑、Markdown 与差异数据模型、深链兼容可沿用。浏览器调试与桌面使用同一套新页面。
- 新窗口采用墨知的暖白 / 金属深灰、陶土强调、同色画布和紧凑控件。单侧导航承载项目与对话，中央专注当前对象，需求对话从审阅页按需展开。窗口和 macOS 应用菜单进入同一设置页，支持 `⌘,`。使用系统 WebView 验证明暗主题、中文输入法、焦点、原生文件选择和最小窗口。
- 视觉层级优先呈现对话正文、需求标题及当前验收状态。对象级操作靠近标题，看板空列保持简洁，审阅页签、正文标题与操作区沿共同边缘排列，并在窄窗口维持可达性。
- 标志采用 Mozi 与 Modu 的近黑圆角方形和白色字形，以对话轮廓构成简化的「问」。同一标志用于网页、工作区、首次运行与桌面图标。安装和更新继续识别原包名及资料目录。
- 桌面检查器通过独立原生窗口预览网页，保留网址输入、导航、刷新及用系统浏览器打开。预览窗口与主工作区隔离，支持本机开发 URL。浏览器调试入口仍提供 Web 预览。
- 服务沿用当前数据目录、旧目录解析及 Pi 凭据位置。对话、需求、项目、已保存文档、设置和工作区直接读取。在 Tauri 宿主中通过应用自身的稳定存储保存界面偏好及需要跨进程恢复的编辑草稿，网页缓存随宿主独立。首个切换版提示升级前保存内容，并允许界面偏好按默认值重新建立。保留旧 Electron 配置目录，以便回退。

## 分批交付

1. **新界面与 macOS arm64 本机包**。先用真实 WebView 验证 HTTP、WebSocket、Node/Pi RPC、PTY、审批事件及资源路径。按新设计完成导航、对话、项目、需求审阅、设置和辅助工具，从桌面包打开现有数据的隔离副本，完成对话与工作台主路径。提供独立的 Vite 调试入口、桌面联调入口和正式包启动日志，错误页能重试及打开诊断位置。
2. **旧版升级与多平台候选**。完成 macOS x64、Windows x64 和首个 Tauri 版本的发布配置。保留旧客户端识别的 macOS zip、Windows setup、`latest.json` 与 `SHA256SUMS.txt`，提供 Windows 便携启动的等效入口。以旧正式版验证应用内原位升级，包括 Windows 静默安装路径、旧快捷方式、卸载登记与重启。Tauri 后续版本采用官方签名更新器，使用单独的清单，更新失败可重试。继续用 GitHub `latest` 与既有安装脚本，沿用当前 macOS 本地信任流程。正式发布另需授权。
3. **切换桌面构建入口**。候选具备首装、应用内升级和数据恢复证据后，移除 Electron、electron-builder、preload、Electron-as-Node 和旧宿主实现。保留服务端和浏览器调试入口，更新开发、安装和验证文档。首个 Tauri 候选和后续升级候选分别验证。

## 验收

| 场景 | 通过条件 |
| --- | --- |
| 原生入口和调试 | 从源码可分别调试 Vite、Node 服务和 Tauri 宿主。从包冷启动进入工作台。必要资源缺失或服务退出时有可读中文错误，重试只启动一个受管理进程。日志不包含凭据或会话票据。 |
| 页面与视觉 | 从单侧导航进入对话、项目、待处理和设置。项目可直接打开需求，中央可审阅设计、模块、交付、验收与历史。打开和关闭对话、辅助工具与网页预览后能回到原对象和阅读位置。实际桌面包检查明暗主题、正常与最小窗口。按页面设计核对现有能力的入口与结果。 |
| 设置与输入 | 窗口入口及 macOS 菜单打开同一设置。修改主题与工作区后立即生效并可重开恢复。检查明暗首帧、默认窗口、`533 × 600`、键盘、中文输入法及文件选择取消。 |
| 主任务与恢复 | 在已有数据的隔离副本中完成自由对话、项目需求、PRD、受审批的 Pi 执行、交付回读及真实 PTY。退出和更新等待持久化，错误后仍可继续工作或重试。重复启动聚焦已有窗口，旧实例或另一个服务占用数据目录时提示处理。 |
| 权限和代理 | 应用窗口仅接受当前受管理的本机来源。外页不能调用桌面命令、加入会话或读取服务数据。验证授权目录、代理设置和模型连接，包含命令退出和 WebSocket 断线恢复。 |
| 首装与升级 | 在对应平台实机检查全新安装、Electron → Tauri、Tauri → Tauri。升级后重新进入同一项目并读取历史，校验不匹配时中止安装。记录各自结果，候选验证与线上发布分别记录。 |
| 包体和启动 | 用同架构、同 Pi 版本和等价资源集比较 Electron 与 Tauri。macOS arm64 安装后常规文件总字节数目标至少减少 40%，同时记录下载包、冷启动到可交互时长和空闲全进程内存。精简版实测 `365,547,763 B` 作为参考，实施时重建可对比基线。 |

本轮先提交设计供确认。安装依赖、构建、本机运行和测试命令在实施阶段按仓库授权执行。原生现场检查、真实模型调用和正式发布分别记录授权与结果。
