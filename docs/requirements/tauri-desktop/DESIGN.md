# 轻舟新界面设计 · PRD v2

## 1. 视觉方向

取自 Mozi（墨知）的暖白 / 金属深灰同色画布、陶土选中态和细分隔。轻舟以当前会话或需求正文为视觉中心，空态只提示用户可做的第一件事。参考依据为 `markdown-press` 的 `src/styles/workspace.css`、`design-qa.md` 和浅色、金属深灰原生实拍，源码基线为 `2f6b31475f66ba3c9ba66365f2f825bbd669c38a`，结合本地当前工作区只读核对。

用户先找到对象，再读正文、看状态并处理当前动作。列表选中即时换底色，鼠标按下普通按钮有轻微收缩，键盘切换、输入和高频操作即时响应。开启减弱动态效果时关闭收缩与弹层动效。

## 2. 色彩

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 标题、导航、主工作区画布 | `#faf8f3` | `#24272b` |
| 菜单、输入、对话框表面 | `#fffdf8` | `#2b2f35` |
| 正文 / 次级文字 | `#2c2b28` / `#6f6a62` | `#e4e1d9` / `#aaa79e` |
| 分区细线 | `rgba(44,43,40,.10)` | `rgba(255,255,255,.08)` |
| 悬停 / 选中背景 | `#eae5dc` / `#f1e3d9` | `#30353b` / `#363d45` |
| 主按钮背景 / 按钮文字 | `#a65f43` / `#fffaf4` | `#d49b7e` / `#231e19` |

成功、警告、失败和差异增删各有语义色与文字。普通文字对比度至少 4.5:1，必要控件边界和焦点至少 3:1。分区细线用于布局，输入边界单独校验。

## 3. 排版

系统无衬线优先，macOS 中文回退到苹方，Windows 中文回退到微软雅黑。工具栏和列表 14px，辅助文字 12px，正文 15px、行高 1.75，小节 16px，页面标题 20px、字重 600。正文约 720px 最大宽度，短内容靠统一阅读边缘对齐。命令、路径、行号和终端使用等宽字体，代码与 diff 在自己的内容区滚动。

## 4. 控件

- 工具按钮使用 14px 线性图标、6px 圆角和至少 40px 点击区，提供名称、提示与可见焦点。常用动作靠近所操作对象。
- 搜索、输入和普通表面使用 8px 圆角，弹窗 12px。行状态由背景、文字或图标共同表达。异步任务用就地状态、禁用重复提交和保留输入表示。
- 保存设计、确认范围、封存、验收、合入及权限决定使用明确的文字按钮。接近执行入口展示对象、版本和阻断原因。复制、收起及打开辅助工具可用图标。
- 菜单方向键可用，Esc 关闭并恢复焦点。输入法组字期间快捷键不发送消息、不触发审批。后台连接和执行状态变更保留插入点、选区与阅读位置。

## 5. 页面与布局

窗口使用一排顶部工具栏，左侧单组导航，中央一个主要工作区。设置和待处理有固定入口。以下为布局线框，列表内容只表达真实对象和当前状态。

## 6. 层级

主画布用位置、留白和字体组织。侧栏、正文和工具区需要区分时用淡线或表面色差。只有菜单、确认和原生启动错误有独立表面或轻阴影。底部操作区有待处理动作时出现，终端和文件可以在原处打开再收起。

## 7. 实现约束

- 前端组件统一用 Tailwind 4 消费语义化 CSS 变量。颜色、字号、曲线和圆角从同一套主题配置读取。新页面使用轻舟名称、图标与业务内容。
- 一个对象只显示一次当前状态。详情、运行日志、版本与来源从对应内容进入。空态和错误文案只说明实际条件和可做的动作。
- 新页面结构、控制项与主题按此文档实现。数据通过既有协议与状态投影提供，重要事实和确认记录以服务端版本为准。
- 审批、待回答问题、终端会话和草稿按真实对象保持身份。页面切换、恢复、断线或布局变化都应保留所处对象并拒绝迟到的旧结果。

## 8. 窗口与验收

默认 `1280 × 840`。宽窗口可同时打开需求正文和右侧对话，较窄时通过明确的切换入口全宽查看其中一个。宽度低于约 760px 时左侧导航折叠，顶部保留打开导航和返回的入口。最终断点由真实正文、中文标签和差异最小宽度验证。`533 × 600` 最小原生窗口保持输入、审阅页签和主动作可达，横向滚动仅出现在代码或差异内容内。

浏览器先核对页面流程。实际 macOS 与 Windows WebView 记录默认窗口、最小窗口、明暗首帧、界面缩放、长中文标题、中文输入法、键盘、焦点返回和复杂差异。以正在讨论和待验收两个真实工作流状态检查页面，使用隔离工程和同一需求跨页验证草稿及阅读位置。

## 9. 组件实现示例

- 导航选中行采用 `#f1e3d9` / `#363d45` 背景、`#8f4e37` / `#d49b7e` 图标、14px 系统字体和 6px 圆角。选中行显示真实名称，保持 40px 点击区。
- 对话输入采用 `#fffdf8` / `#2b2f35` 表面、15px 字体、1.75 行高和 8px 圆角。发送按钮使用 `#a65f43` / `#d49b7e`，权限与当前模型放在输入区底部工具行。
- 用户消息的陶土气泡包住正文、附件和编辑内容。复制与编辑重试放在气泡下方，鼠标悬停或键盘聚焦时显示，触控窗口直接显示。
- 审阅正文标题使用 20px / 600，正文 15px / 1.75，最大宽度 720px。当前页签使用已选语义与陶土强调色，底部主按钮显示准确动作及对应版本。
