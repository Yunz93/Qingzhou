# 墨问桌面迁移与界面重设计 · 实施记录

实施使用 `f76ee5488c1f98ede475ce3a785743afafcb66a7` 的隔离工作区和 [PRD v2](PRD.md)。用户在等待 v2 确认后恢复重构目标，并明确授权安装、构建、本机运行和测试。

## 首轮

- 新增 Tauri Rust 宿主和独立 Node 服务入口。宿主负责启动握手、受控退出、原生菜单、文件选择、通知与独立网页预览。桌面服务校验单次启动凭据后签发会话，保留同源 HTTP 与 WebSocket 的业务协议。
- 对话、项目、需求审阅和设置替换为新窗口结构。导航采用同色画布和陶土选中态，审阅进入中央页面，需求对话按需展开，工作区工具移到下方。现有业务控件的协议与状态行为逐项迁移。
- 资料仍读取原目录及旧版回退目录。桌面独立保存主题、布局偏好、文本与图片草稿。退出和签名更新等待窗口写入与业务资料落盘。桌面和新版独立服务共用资料目录锁，启动时另检测已知旧版端口的资料路径。
- Tauri 成为桌面开发与打包入口。移除旧宿主、preload、桌面构建依赖与模拟 Node 层。保留旧客户端识别的发布产物命名和摘要清单，新增 Tauri 签名更新清单和 Windows 静默迁移钩子。
- 运行环境、测试结果及未覆盖项详见 [验证记录](VERIFICATION.md)。

## 候选复验

- 名称改为墨问（Mowen）。增加统一 SVG 标志和原生图标。使用旧发布资产名升级时，macOS ZIP 保留原归档入口，Windows 识别旧 NSIS 登记并原位迁移。应用标识与资料路径沿用原值。

- Windows 静默升级从 0.1.26 安装器写入的安装登记读取自定义路径。迁移结束后单独移除旧卸载登记，保留同一路径的入口和用户文件。发布工作流加入便携启动、全新安装和旧目录静默迁移验证。
- 增加 macOS 交叉构建 Windows x64 候选入口。Windows 安装与便携包沿用旧客户端下载名称，包内包含目标架构的 Node、Pi、PTY 和搜索工具。
- Windows 应用内更新校验当前运行目录与 NSIS 的安装登记一致，并在交给安装器前再次校验。运行时和安装器均从应用标识推导发布者。旧版原位升级会检查墨问登记路径中的程序是否仍存在，避免重用已卸载的目录。便携版可以检查并下载新版 ZIP，安装版继续使用签名更新。
- 应用内更新分别提示检查、下载、签名校验及安装错误，并保留重试入口。若系统保留上一版应用副本，错误信息显示它所在的位置。
- 发布验证模式加入 Windows 低版本 NSIS 测试包和本机更新源。用例检查安装版和便携副本并存、拒绝损坏的安装包、正确签名原位更新及重启后恢复资料。测试包与临时签名只用于验证作业。
- 恢复桌面启动时的系统 PAC 解析。macOS 使用 CFNetwork 识别和执行规则，Windows 使用 WinHTTP。显式代理环境变量优先。解析限时，命中代理后同时用于本机服务、Pi 和签名更新，保留签名更新的回环及 `NO_PROXY` 例外。
- 桌面自动化包使用独立的 Cargo 输出目录。发布工作流从该目录运行 WebView2 和签名更新用的旧版本夹具，避免同架构并行打包时混用成品和测试程序。
- 对话框的发送与排队快捷键统一尊重输入法组合状态。发布说明提示旧客户端用户在升级前保存编辑内容。
- 让内置启动页发起启动并直接显示中文错误，校验包内必要运行文件。会话交接先加载同源文档，再进入工作台，保留严格 Cookie，修复 WKWebView 首次跳转丢失认证的情况。
- 打包时验证暂存的工作台 HTML 及它引用的构建资源，避免前端重新构建期间产出缺少页面的安装包。
- 本机服务断开后，重连会把尚未写入的界面状态和草稿交给受管理进程保存，再加载工作台。写入失败时保留原窗口，可处理资料目录后再次重试。
- 桌面端退出时先落盘，再关闭仍然打开的本机 WebSocket 和 HTTP 连接，避免等待窗口完成网络关闭。Windows 源码构建配置提供应用图标，可直接运行 Rust 编译检查。
- Vite 开发代理读取与服务相同的 `PORT`。指定其他服务端口时，HTTP、WebSocket 和上传请求都能连接到该端口。
- macOS 安装脚本在主进程管理下载、解包和磁盘映像挂载，退出时清理临时文件并卸载映像。`--local` 和 `--build` 按当前架构选择候选包，优先使用 ZIP。
- Windows 一键安装脚本为每次下载创建独立的临时目录，根据 NSIS 安装器的退出码报告结果，并在成功、下载失败和安装失败时清理该目录。
- 将用户消息的复制、编辑重试和失败状态移至气泡下方。气泡高度由正文、附件和编辑区决定，操作保持 40 px 点击高度。
- 新对话弹窗在工作区资料异步到达后显示默认目录。用户手动选择或输入后，继续使用其选择。
- 根据实际界面精简会话、看板与审阅层级。克隆会话移至标题栏，消息操作保持 40 × 40 px。看板上的需求卡片、空列与状态各有清晰重心。审阅页签和正文标题使用统一边距。
