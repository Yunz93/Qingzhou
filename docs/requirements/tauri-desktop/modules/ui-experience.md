# 轻舟界面 · 新工作区提案

来源为 [PRD v2](../PRD.md)。本版待确认。页面结构、主题、控件与验收以[页面设计](../DESIGN.md)为准。相关业务依据为[对话](../../../modules/conversation.md)、[项目工作编排](../../../modules/work-orchestration.md)和[需求设计](../../../modules/requirement-design.md)。

## 职责

新应用壳拥有窗口导航、当前项目和对象、侧栏与辅助面板的布局。页面按自由对话、项目、需求、待处理和全局设置组织。设置与首次启动、断线重连、失败恢复共享新主题。现有业务状态和网络契约通过无界面数据层接入，现有页级组件、布局和主题退出桌面与浏览器调试的入口。

## 信息与动作归属

- 导航负责定位对象。中央负责阅读、编辑、当前状态和下一步。需求对话按需求身份打开，工具区跟随当前会话或工作区。切换页签、面板和窗口尺寸沿用原对象及草稿。
- 会话克隆放在标题栏，消息正文与逐条操作留在时间线。看板卡片突出需求标题，空列只显示列名、数量和空态。审阅页当前状态使用主题语义色，页签、正文标题和底部动作采用同一组边距。
- 未保存草稿、保存冲突、权限要求和真实检查失败以就地提示呈现。审批和提问绑定确切会话或需求。交付、人工验收、候选复审与合入各用服务端的对应状态和动作。
- PRD 旧链接、已有项目和需求标识映射到新路由。UI 偏好使用 Tauri 端稳定存储，先读后写，旧版缺省字段回退。真实数据仍由服务端和旧数据目录管理。

## 验证入口

复用既有协议、服务与真实 Git 回归。用新页面的用户路径覆盖自由对话转需求、设计到合入、跨对象切换、草稿恢复、键盘、中文输入法、原生选择文件以及实际窗口尺寸。截图取自新页面和目标 WebView，附确切主题、窗口、夹具和进程环境。
