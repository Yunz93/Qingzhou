## 持久化与恢复

写文件前持久化含旧字节与预期字节的日志；状态确认保存后完成日志。恢复只回滚仍匹配本次字节的文件，不覆盖外部编辑。历史 MD 缺失或 hash 不符时明确报错。合入记录独立的索引树和预期 blob，CAS 前的恢复只撤销本次暂存；重启不自动确认、执行或合入。

新模块的初始文件仅在未被主线跟踪，且原目录精确等于初始正文、候选精确等于已确认提案时允许前进。该例外不放宽用户文件与人工索引保护。

## 发布复核修正

- 文档绑定在文件写入成功后才发布到状态；导入写入失败不会遗留无效绑定或丢失旧 JSON 正文。
- 封存及候选复核检查登记的不可变文档版本；其他需求的整个快照目录按实际绑定保护，覆盖自定义路径的 CONTEXT.md 与基线。
- 验收和合入共享项目文档锁，模块版本分配、写文件和发布状态串行执行。
- 候选没有修改的已跟踪文档草稿保留；受控暂存后检查捕获索引树的全部路径、文件模式和 blob，拒绝夹带并发人工暂存。
- 导入前的 JSON-only 工作区仍可显式继续；已导入的初始模块文件按精确登记基线衔接，保留手工文档保护。
- 同步入口使用协议正文限制，拒绝超长外部模块提案；目录和完整文档路径采用不同长度预算，生成绑定写入前校验。
- 状态只对 PRD、其模块变更和模块版本省略正文；结构化提案保留正文，并剔除 Agent 输入携带的服务端路径绑定。
- 历史检查的组合差异仍比较源交付与候选；合入事件按合入前主线与实际候选读取文件差异，分别标明比较依据。
