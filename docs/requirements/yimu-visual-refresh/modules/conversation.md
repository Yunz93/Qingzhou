# 对话视觉提案

依据：[PRD v2](../PRD.md)，代码基线 `f448319` 及本轮尚未提交的 v1 视觉实现。本提案未声明验收。

共享主题采用纸白、灰绿和森林绿；侧栏与连续对话有柔和的材料区分，当前会话和模式清晰选中。首页、品牌标题少量使用宋体，消息正文与代码仍保持原有可读性。输入框焦点、错误及运行状态有独立辨识。

只改变视觉和必要的样式挂点；草稿、滚动、任务身份、模式往返和审批行为维持原有契约。验证入口为 `tests/e2e/workbench.spec.ts`、`frontend-interactions.spec.ts`。

v2 增加对话阅读层次：用户轮次、正文、思考和工具过程分别呈现；流式正文使用稳定 Markdown 组件和延后更新，结束时不切换为另一套渲染。语法高亮在生成结束后执行，代码块可直接复制。失败过程自动显露，成功的读取和思考仍可折叠。宽代码 / 表格仅内部滚动，正文段落、标题、列表、引用各有间距。新增验证入口为 `tests/e2e/conversation-rendering.spec.ts`。
