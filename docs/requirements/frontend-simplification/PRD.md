# 前端信息精简

状态：依据用户“review 前端，去掉不必要的元素和说明”实施，待验收。

## 目标与范围

减少工作模式主流程中的重复状态、教学说明、空栏目和并列低频操作；保留当前阶段、下一步操作、失败原因与关键确认。沿用现有布局和功能，不改变后端权限与业务状态。

## 改动

1. 项目总览减少重复统计和说明，运行细节折叠，标准文件入口归入项目设置。
2. 需求工作区保留一套阶段进度，清理重复标题与状态；工作区分支等信息按需展开。
3. PRD 突出范围、正文和当前确认动作；移除重复规则说明，代码基线及文档路径收进详情。提案采用、过期草稿提示和版本历史继续可用。
4. 交付页隐藏没有内容的未完成项、产物栏目；检查状态和检查日志分层，封存的可选补充信息折叠。
5. 集成通过复审后显示已保存结论，修改结论按需展开；保留独立合入确认。精简模块页、空状态、讨论模式和弹窗中的重复说明。

## 验收

- 首屏聚焦当前需求及主要动作，不重复展示两套阶段进度。
- 必要的范围确认、PRD 确认、文件归属、验收与候选合入确认保留。
- 技术详情、产物、失败日志和低频设置仍能访问。
- 桌面与手机无横向溢出，键盘可展开详情；现有工作流回归通过。
- 查看项目标准文件后返回编排设置，未保存的设置和焦点保留。

本轮先按组件源码检查，浏览器连接不可用；通过项目原有 Playwright 回归及本轮生成截图验证实际呈现，不声称完成独立的交互或无障碍审计。
